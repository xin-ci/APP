# 全屋管理 App（可上架苹果商店）产品与技术方案

## 1. 产品目标
打造一个支持“空间树状管理 + 可视化操作”的 iOS 应用，帮助用户快速管理家中空间与物品，核心支持：

- 第一层：我的家
- 第二层：房间
- 第三层：柜子
- 第四层：柜内物品
- 以及：任意节点下新增一层（自定义子空间）

## 2. 信息架构（可扩展多层）

> 设计原则：不要把层级写死为 4 层，而是统一抽象为「空间节点 + 物品节点」。

### 2.1 节点类型

- `space`（空间节点）
  - 例如：我的家、客厅、衣柜、抽屉、收纳盒
- `item`（物品节点）
  - 例如：护照、充电线、工具箱

### 2.2 核心字段建议

#### SpaceNode
- `id`: 唯一 ID
- `name`: 名称
- `parentId`: 父节点 ID（根节点可为空）
- `icon`: 图标
- `color`: 主题色
- `sortOrder`: 排序
- `note`: 备注
- `createdAt` / `updatedAt`

#### ItemNode
- `id`: 唯一 ID
- `name`: 物品名称
- `spaceId`: 所属空间
- `quantity`: 数量
- `photoUrls`: 图片
- `tags`: 标签
- `expiryDate`: 保质期/到期日（可选）
- `note`: 备注
- `createdAt` / `updatedAt`

### 2.3 关系说明

- 一个 `space` 可以包含多个子 `space`
- 一个 `space` 可以包含多个 `item`
- 因为是树形结构，所以天然支持“新增一层子空间”

## 3. 页面与交互（可视化为核心）

## 3.1 首页：空间可视化总览

- 顶部显示当前家庭名称（如：我的家）
- 中间采用“卡片 + 层级路径”展示当前空间下的子空间
- 支持两种视图切换：
  - 网格视图（适合空间）
  - 列表视图（适合快速编辑）
- 底部固定「+」按钮：新增空间或新增物品

## 3.2 路径导航（Breadcrumb）

- 示例：我的家 / 主卧 / 衣柜 / 上层抽屉
- 点击路径任一层可快速回跳

## 3.3 可视化操作建议

- 长按卡片进入编辑模式
- 拖拽排序（柜子/物品重排）
- 拖拽移动（把物品拖到另一个空间）
- 批量模式（多选后移动、打标签、删除）

## 3.4 详情页（空间详情 / 物品详情）

### 空间详情
- 基础信息：名称、图标、备注
- 子空间统计：子空间数量、物品数量
- 使用热度：最近访问时间、最近编辑

### 物品详情
- 物品照片轮播
- 所在路径（可点击跳转）
- 数量、标签、备注
- 相关提醒（例如保质期提醒）

## 4. iOS 技术实现建议（便于上架）

## 4.1 推荐技术栈

- 前端：SwiftUI
- 本地数据库：SwiftData（iOS 17+）或 Core Data（更广覆盖）
- 图片存储：本地文件 + 路径索引
- 云同步（可选）：CloudKit

## 4.2 架构建议

- `Presentation`：SwiftUI View
- `Domain`：用例（新增空间、移动物品、查询路径）
- `Data`：Repository + 本地持久化
- `Model`：Space / Item / Tag / Reminder

## 4.3 关键能力实现

- 树结构查询：递归或路径缓存
- 防循环校验：移动空间时禁止移入其子节点
- 搜索：按名称、标签、路径模糊检索
- 离线优先：所有操作本地可用，联网再同步

## 5. App Store 上架关键点（必须提前设计）

- 隐私政策页面（如果有账号/云同步/分析）
- 数据收集说明（App Privacy）
- 明确账号删除流程（若提供账号系统）
- 不使用侵权图片或未授权商标
- 截图与预览视频要真实反映功能
- 不做误导性订阅文案

## 6. MVP（第一版）建议

### 必做功能

1. 创建家庭（默认一个“我的家”）
2. 新增/编辑/删除空间
3. 新增/编辑/删除物品
4. 多层级浏览与路径导航
5. 搜索与筛选
6. 本地持久化

### 第二阶段功能

1. iCloud 同步
2. 分享家庭成员协作
3. 物品到期提醒
4. AI 辅助归类（拍照识别物品）

## 7. 示例用户流程

1. 用户首次进入 App，自动创建“我的家”
2. 在“我的家”下新增“主卧”
3. 在“主卧”下新增“衣柜”
4. 在“衣柜”下新增“上层抽屉”（新增子空间）
5. 在“上层抽屉”中添加“护照”物品
6. 点击护照进入详情页，查看数量、备注、图片

## 8. SwiftUI 页面清单（建议）

- `HomeTreeView`：空间总览
- `SpaceDetailView`：空间详情
- `ItemDetailView`：物品详情
- `CreateOrEditSpaceView`：新增/编辑空间
- `CreateOrEditItemView`：新增/编辑物品
- `SearchView`：全局搜索
- `SettingsView`：隐私政策、备份与恢复
